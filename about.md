# About War Weeker

(Written from the perspective of what is on my local machine, not all that is in github)

Last year I made Competiscore (can be found one directory up (also at https://github.com/paul-macfarlane/competiscore), with data dumped one directory up as well).

We used it for war week, and it certainly did the job. However, I tried to make it too generic. I think this time around, we'd benefit from a more specific tool that is all about war week.

In addition to the core competition features (see competiscore for that), I'd like to add some other bells ans whistles.

- Historical War Week References
- Customized Theme Per War Week
- Integration with the JG Stairs app
- A bulletin board for announcements (text and video), schedule, etc.

Some other places to draw inspiration from:
- https://www.jahnelgroup.com/
- https://sites.google.com/jahnelgroup.com/jahnel-group-wiki/home?authuser=0 (I'm hoping to get access to the raw content, but I suppose if Claude can use my browser this will work.) This also has a lot of historical content.

I am hoping to get access to the stairs app soon, so we will have the ability to investigate what an integration might look like.
