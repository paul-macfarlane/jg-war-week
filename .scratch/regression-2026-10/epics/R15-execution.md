- **85:** one `@layer base` rule in `globals.css`: `button`, `a[href]`, `[role=button]`, `[role=option]`, `[role=menuitem]`, `[role=tab]`, `[role=switch]`, `[role=checkbox]`, `select`, `summary`, `label[for]` get `cursor: pointer`; `:disabled` and `[aria-disabled=true]` get `not-allowed`. Remove `cursor-default` from the combobox item. The spec reads computed cursors on a button, a link, a combobox option, a tab, and a disabled button.
- **86:** the header's inner row becomes `grid grid-cols-[1fr_auto_1fr]`; the left link `min-w-0` with the tagline truncating; the account menu `justify-self-end`. Below `lg` the nav is hidden and the row still lays out name left, menu right. The spec asserts the nav's centre within 4px of the header's centre at 1280 and 1024 wide on `/xi` and `/xii`, with screenshots.
- **87:** primary actions `default`, secondary `outline`, `ghost` only for icon or tertiary actions. The Heat card gets a visible solid "Record result" button (and "Edit" for a recorded Heat as `outline`) instead of a `text-primary` span in a full-card ghost button. The worker audits admin and Participant pages and returns the audit list (action, file, old → new variant). The spec screenshots the admin Bracket with the solid Record result.
- **88:** extract the chrome (ThemeRoot, TopNav, YouProvider, footer, BottomTabBar, and the account/You resolution) from `[edition]/layout.tsx` into a shared server component taking a War Week. `[edition]/layout.tsx` and a new `src/app/history/layout.tsx` (current War Week via `getCurrentWarWeek`, as `/` does; `notFound()` if none) both render it. `/history` keeps its URLs; its "Back to War Week" link goes; no nav item is active there. The spec checks the top nav at 1280 and the tab bar at 390 on `/history` and a Category page, with the current War Week's `--light-primary` on `[data-theme-root]`. Smoke's `/history` 200 stays.
- **89:** reproduce first, from code (and a component or unit test), and record the steps. Fix `GamesBuilder` so the form shows the saved values after `router.refresh()` (resync from props, or key the form on the saved values). Make a trailing or doubled comma not become a 0. If the reproduction shows the value landed in the other field (Finish Points vs Placement Points), record that and make both fields' labels say which is which; no field is removed (R16 does that). The spec sets Games settings and Placement Points, saves, leaves, comes back and sees both.
- **DX:** checklist lines for the Bracket, nav, `/history`, Games settings and the cursor; the maintainers guide's UI section gets the button-variant rule; `/about` copy and stills only where a change is visible in them. `CONTEXT.md`: the grilling's glossary list names nothing that R15 ships, so no change unless a term R15 touches disagrees.
