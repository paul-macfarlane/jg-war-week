# Grilling record, 2026-10-03

`/grill-with-docs` on Paul's third regression feedback (admin Competition
setup, Points, Brackets, Games, Participation; Participant list and nav), with
Paul. Evidence: code surveys of the Competition model and Points, Brackets /
Heats / Games recording, the Participant pages, and the seeds' Points Entries.

## Facts established (no decision needed)

- **Formats today:** `points`, `single-elimination`, `heats`, `games`
  (Game Types `head-to-head`, `best-score`, `ranked`), `participation`.
  Brackets, Games and Participation write Points Entries
  (`generated_by_bracket`) on Finalize / Close; a `points` Competition is
  hand-typed Points Entries, one target per submit, free-form points; the
  1st/2nd/3rd buttons only fill the Points input.
- **Max Points** never caps Standings: it validates 1st's Placement Points,
  soft-warns an over-max entry, and shows "Max N / No max".
- **Placement Points:** up to 5 places (`MAX_PLACEMENTS`), non-increasing.
- **"Run as a bracket"** is a link to the Bracket page, whose Format select
  switches `points` ↔ Bracket Formats.
- Every **Points Entry** needs a Competition.
- **Hosts:** an email-chips field (`JgEmailChips`), Organizer-only.
- **Description:** plain text, 2000 chars, shown on the Competition page only.
- **Single elimination vs Heats:** one Bracket model; single elimination is
  Heats of 2 with 1 advancing. No 3rd place game (both semifinal losers tie
  3rd). "By Standings" seeds by current Standings. Forfeit puts an entrant
  last. Heats carry Day, start time and location ("Time & place").
- **Heats highlight bug:** admin results (`HeatRows`) bold only 1st; the
  Participant tree bolds every advancer.
- **Admin has no tree;** "Run results" is a link to round cards.
- **Game scores** are logged only on the Participant Competition page.
- **"5, 3, 1" after reopen:** Games have two such fields (per-Game Finish
  Points in Games settings; Placement Points in the Competition sheet). Not
  reproduced; `GamesBuilder` state doesn't resync after save.
- **Participant nav:** `justify-between` with an uneven left block pushes the
  links right. `/history` has no layout, so no nav. No global pointer cursor
  (Tailwind v4). Comboboxes filter the whole list in the browser, no cap.
  The Competitions list shows a max badge, scoring and Format, but no
  description, status or round.
- **Seeds:** typed Points Entries exist only in War Week XI (`seeds/xi.json`,
  22 `points` Competitions, 24 entries, one per Team, all team-scored) and the
  two demo seeds. Ranked Games: only Electric City Matrix (demo XI), no Finish
  Points, no Games logged. XII demo's Step Challenge sums daily fractional
  entries. **None of this data is in use yet.**

## Glossary changes to land with the work

Each ticket updates `CONTEXT.md` when it ships, not before:

- **Placement** (Format): one result, every Placement recorded at once;
  **Placement** (row): a place and an optional Score; **Record placements**.
- **Discretionary points**: points with no Competition, a reason, Organizers
  only. Replaces "Points Entry" as the admin page name.
- **Format**: Placement, Head-to-head, Best score, Bracket, Participation.
  **Game Type**, **ranked**, **Finish Points**, **Max Points** retired.
- **Bracket**: heat size and advancing; **3rd place game**; **Reset bracket**.
  **Forfeit** and Heat time/location retired.
