## Questions and answers

Round 1

- **Q1, scrap the MCP?** Remove it all: route, `src/mcp/`, `MCP_TOKEN`,
  packages, smoke, docs and the `planning.md` entries. `llms.txt` is built
  from the MCP tool list, so it goes too.
- **Q2, cut copy settings?** Cut copying entirely. "No War Week is
  guaranteed to be like the last."
- **Q3, where does Create next War Week go?** In the **Lifecycle** section,
  only when the latest War Week is over. "We are never going to create a new
  War Week unless the old one is over."
- **Q4, Announcements in a dialog?** Yes for create. Edit should follow one
  consistent rule (Q9).
- **Q5, the later-Match message?** (b) mark only the locked Matches: lock
  icon, disabled control, the reason as a tooltip.
- **Q6, `/about` images?** As recommended: drop the three-phone image, one
  feature per row with readable images, cut any feature still unreadable.
- **Q7, center small Brackets?** Yes, Participant and admin trees.
- **Q8, participation checkbox?** A bug; fix it as one. Likely cause
  (sub-agent, not reproduced): `participation-builder.tsx` drops its
  optimistic entry right after an un-awaited `router.refresh()`.

Round 2

- **Q9, a create/edit rule:** a record is created and edited in the same
  dialog; only a thing you run (a Competition) gets a page. Agreed.
- **Q10, "latest War Week":** by **start date**, not edition number.
- **Q11, Entrants autosave:** yes.
- **Q12, Head-to-head "A vs B" pickers:** yes.
- **Q13, participation layout:** (c) leave it.
- **Q14, Competition list tabs:** (a) `?group=<slug>`, history replace.
- **Q15, Schedule item Host:** Participants, and support **several** Hosts.
- **Q16, no start time:** "Any time", first in the day, never in Now/Next.
- **Q17, Category then Competition:** yes.
- **Q18, how many specs:** two, for big chunks.

Round 3

- **Q19, latest by start date, server-enforced:** yes.
- **Q20, Schedule item Host storage and role:** implementation detail, left
  to the spec: a join table, display only, no Host access.
- **Q21, moving free-text Hosts:** no data migration; nothing real exists.
