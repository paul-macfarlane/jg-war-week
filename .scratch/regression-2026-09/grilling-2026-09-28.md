## Ticket 17: the `games` Format

| # | Decision |
|---|---|
| Q1 | Build Competitions decided by logged Games; the Game log is the activity record. Non-Competition tracking (attendance, steps) is out. |
| Q2 | One logged contest is a **Game**. A Heat stays Bracket-only. |
| Q3, Q23 | A new Format, `games` ("Games"), beside `points`, `single-elimination` and `heats`. |
| Q4, Q9 | One **Game Type** per Competition: `head-to-head`, `best-score`, `ranked`. |
| Q17, Q18 | One-off contests are **not** Brackets. A Bracket means a tournament. A single head-to-head showdown, a best of X, and a single free-for-all are `games` Competitions. |
| Q10, Q24 | `head-to-head` ranks by most wins, any number of Entrants. Optional **Best of** (off, 3, 5, 7; best of 1 is a one-off) needs exactly 2 Entrants; when one side reaches a majority, logging stops and the Host is prompted to Close. |
| Q11 | Per-Competition **Draws allowed**, off by default. |
| Q12 | `best-score`: **Count** = best or total; **Better is** = higher or lower; a unit label (seconds, WPM, trips). |
| Q13, Q19 | `ranked`: a finishing order per Game; **Finish Points** per position, set by the Host, summed across Games; leaderboard by total. Default: one point per player beaten. Ties within a Game share the higher finish. |
| Q14 | Entrants follow scoring: Participants (individual) or Teams (team). No Squads. In team scoring, any Participant on either Team can log. |
| Q25 | Host picks per Competition: **open to everyone** eligible (default for recurring play) or a **fixed Entrant list** (default for Best of and showdowns). |
| Q6, Q21 | A player in the Game logs it; it counts at once. The logger can edit or delete their Game until close; others ask the Host. The Host or an Organizer can edit or delete any Game. No confirmations. (ADR 0006) |
| Q5, Q15 | The Host presses **Close**: the leaderboard's top finishers get Placement Points (same tie rule as finalizing a Bracket). Optional close time stops logging but awards nothing until the Host confirms. **Reopen** withdraws the points; a closed Competition refuses Games. |
| Q20 | The Competition page shows the leaderboard and the Game log newest first, with a "Mine" filter. Columns: head-to-head: played, W, L, D; best-score: best or total, played; ranked: Finish Points, played, wins. No streaks or records yet. |
| Q22 | Home shows a "Log a Game" shortcut to a Participant who can log in an open `games` Competition. |
| Q26 | Games have no time or place; a showdown gets a Schedule Item linked to the Competition. |
| Q7, Q16 | People across War Weeks is in scope as a nice-to-have (ticket 20), not part of 17. |

## Ticket 15: self-enrollment

| # | Decision |
|---|---|
| Q32 | Per-Competition "Participants can enroll" switch, off by default. Applies to fixed-list Competitions: Brackets and fixed-list `games`. |
| Q33 | Enrollment closes at whichever comes first: Bracket built, optional Entrant limit reached, optional close time, the Host closes it, or (for `games`) the first Game logged. Best of X is Host-set, never self-enrolled. |
| Q34 | Team scoring: any Participant on a Team enters or withdraws their Team; Leader stays a label. Squads Brackets: Participants join or leave a Squad the Host created; they can't create Squads. |
| Q35 | A Participant can withdraw until enrollment closes; after that only the Host or an Organizer removes an Entrant. |
| Q37 | ADR 0006 records these writes. Access change: the plan is red-teamed. |
| Q38 | Keep the word **Squad**; add one line of help text wherever it appears ("a pair or group from one Team, playing as one entrant"). |
