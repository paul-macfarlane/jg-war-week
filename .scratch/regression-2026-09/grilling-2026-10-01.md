# Grilling record, 2026-10-01

`/grill-with-docs` on Paul's second regression feedback (Participant pages
P1–P8, Admin A1–A18, regression checklist), with Paul. Evidence: code surveys
of the nav, identity, lifecycle, admin lists and sheets, and a survey of
`old-wikis/` for recurring Awards and participation points.

## Facts established (no decision needed)

- **Account linking across years (P7a):** each War Week has its own
  Participant records; the session email is matched to each War Week's roster
  email at read time, ignoring case. The same email on XI and XII links in
  both. Cross-year history stays ticket 20.
- **Upcoming vs Live (A1):** no way back to `upcoming`. Live only decides
  which War Week is current, enforces one-live-at-a-time and turns on the
  Setup warnings; nothing is hidden before Live.
- **Testing other roles (A2):** no impersonation or test login exists; e2e
  writes sessions to the database. A `+1` alias never signs in as a separate
  Google account. Organizers have no invite: an added email takes effect at
  that person's next sign-in, no email sent.
- **Organizer overview (A3):** one sentence of links.
- **Roster edit (A7):** the whole row is an unmarked button. Admin lists use
  three edit patterns (row opens sheet; Days inline; Edit link to a page).
- **Sheets (A8):** `ResponsiveSheetDialog` switches at `lg` (1024px); the
  Squad form is a bottom sheet at every width.
- **Awards (A9):** no categories. Recurring in the wikis: War Week MVP
  (2019–2026 except 2021), Billable Hours Champ / Top Billers (every year,
  logged in Tense), Midnight Club → Black Midnight (2021–2026), Core Values
  Grow/Grind/Serve/Inspire (2021).
- **Participation (A17):** nothing exists. Wikis use 1 point per finisher,
  teams ranked by finisher count (10/5/3/1), and points to the team with the
  most finishers.
- **Editor (A5):** journeys' editor adds headings H1–H3, underline,
  strikethrough, quotes, image captions, an image tools menu, keyboard
  shortcuts and a placeholder.

## Glossary changes to land with the work

Each ticket updates `CONTEXT.md` when it ships, not before:

- **Announcement**: rich text only (no separate video links). "News" banned
  as a UI term for it.
- **Profile** / **Profile name**: an account's own name and picture, shown
  app-wide where the account is linked by email; overrides the roster name.
- **You**: found by account linking only (the pick is gone).
- **Account menu**: the avatar menu.
- **Test sign-in**, **View as**.
- **Unstart**: `live → upcoming` while nothing is scored.
- **Participation** Format; **Award Category**; **Finale slide**,
  **Custom slide**.
